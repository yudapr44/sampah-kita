# SampahKita - System Pengelolaan & Edukasi Sampah Desa Balonggandu

SampahKita adalah platform sistem informasi pengelolaan sampah, edukasi 3R (Reduce, Reuse, Recycle), dan Bank Sampah Digital berbasis komunitas Desa Balonggandu, Kecamatan Jatisari, Kabupaten Karawang.

## Fitur Utama
- **Halaman Utama (Home)**: Informasi program desa, galeri, dan profil lokasi Google Maps Desa Balonggandu.
- **Modul Edukasi 3R**: Artikel praktis pemilahan sampah, pembuatan insinerator minim asap, lilin aromaterapi dari minyak jelantah, dan kompos organik.
- **Bank Sampah Digital**: Fitur pengelolaan nasabah, transaksi penimbangan sampah, dan statistik bank sampah.
- **Dashboard Admin**: Pengelolaan artikel, pesan kontak, pengunjung harian, dan statistik sistem.

## Teknologi
- Laravel 11
- MySQL Database
- Tailwind CSS & Material Symbols
